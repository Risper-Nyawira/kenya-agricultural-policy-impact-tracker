# Kenya Agricultural Policy Impact Tracker

Research project | In progress | October 2026

## Purpose

This repository documents an evidence-based tracker for assessing Kenyan agricultural policies and programmes. It separates implementation evidence, reported monitoring results, descriptive outcomes, and credible causal impact evidence.

The tracker assesses five impact dimensions:

1. Agricultural productivity
2. Farmers' livelihoods
3. Market outcomes
4. Food security and resilience
5. Sustainability

It also assesses equity, efficiency/value for money, data quality, limitations, and attribution.

## Repository structure

- `methodology/` — reusable 18-step assessment framework.
- `data/` — data-access and provenance policy; raw data are not published here.
- `interventions/` — public case-study summaries.
- `analysis/` — cross-cutting preliminary findings.
- `docs/` — limitations, next steps, and evidence standards.
- `workbooks/` — public, preliminary Excel research artifacts.

## Evidence standard

The repository does not treat a trend, reported project result, or target achievement as proof of impact. Causal claims require an exposure-linked dataset and a credible counterfactual, such as a valid comparison group or a rigorous baseline/endline design.

Public workbook artifacts are included for transparency. They contain only public-source documentation and preliminary analysis. Raw source files, personal data, restricted programme records, and internal working files are excluded.
