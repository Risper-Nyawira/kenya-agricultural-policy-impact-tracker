# Data Policy and Provenance

This repository does not publish raw programme data, personal data, restricted administrative files, or raw source downloads.

Each workbook has a Sources sheet, Acquisition Log, Data Quality assessment, and Data Request specification. These provide provenance without redistributing materials that may be restricted or contain sensitive information.

Before adding a dataset to this repository, confirm that:

1. It is public or publication is authorised.
2. It contains no personal identifiers or sensitive information.
3. Its licence or terms permit redistribution.
4. The source, access date, coverage, methodology, and limitations are documented.

The public workbooks are research artifacts built from public documents and aggregate official statistics. They are not official programme databases.
