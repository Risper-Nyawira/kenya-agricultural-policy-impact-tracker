# Limitations and Next Steps

## Shared limitations

- Public sources are largely aggregate and do not identify beneficiaries over time.
- Public reports may contain preliminary, revised, or deduplicated monitoring figures.
- Public documentation rarely provides questionnaires, sampling frames, weights, or raw survey data.
- Expenditure and procurement records needed for value-for-money calculations are not publicly available in the required detail.
- A pre/post change or a reported indicator value is not a causal impact estimate without a credible counterfactual.

## Priority next steps

1. Submit anonymised data requests for beneficiary/service registers, survey microdata, expenditure ledgers, and MTR technical documentation.
2. Obtain comparable non-beneficiary or comparison-area outcome data.
3. Review data quality before cleaning or merging files.
4. Conduct descriptive implementation and outcome analysis.
5. Select a causal method only when the data support it, for example difference-in-differences or matched comparison analysis.
6. Update summaries and workbook findings with a clear distinction between reported, descriptive, and attributable evidence.

## Responsible use

The repository should not be used to rank institutions or make funding decisions without validation from implementing agencies and access to the underlying evidence.
